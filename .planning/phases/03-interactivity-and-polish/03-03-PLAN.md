<task type="auto">
  <name>Task 1: Configure comprehensive metadata in layout.tsx</name>
  <files>
    src/app/layout.tsx
    src/data/portfolio.ts
  </files>
  <action>
    1. First, ensure portfolio.ts has the necessary data. If missing, add to personalInfo:
       - `siteUrl`: "https://yourdomain.com" (placeholder for now)
       - `ogImage`: "/og-image.png" (will need to create or use placeholder)

    2. Update layout.tsx metadata export to use Next.js 16 Metadata API:

    ```tsx
    import type { Metadata } from "next";
    import { portfolio } from "@/data/portfolio";

    const { name, title, tagline } = portfolio.personalInfo;
    const siteUrl = portfolio.personalInfo.siteUrl || "https://example.com";

    export const metadata: Metadata = {
      title: `${name} | ${title}`,
      description: tagline,
      keywords: ["software engineer", "full stack developer", "portfolio", "web developer"],

      // Open Graph for Facebook, LinkedIn, etc.
      openGraph: {
        type: "website",
        locale: "en_US",
        url: siteUrl,
        siteName: name,
        title: `${name} | ${title}`,
        description: tagline,
        images: [
          {
            url: `${siteUrl}/og-image.png`,
            width: 1200,
            height: 630,
            alt: `${name} - ${title}`,
          },
        ],
      },

      // Twitter Card
      twitter: {
        card: "summary_large_image",
        title: `${name} | ${title}`,
        description: tagline,
        images: [`${siteUrl}/og-image.png`],
      },

      // Robots
      robots: {
        index: true,
        follow: true,
        googleBot: {
          index: true,
          follow: true,
        },
      },

      // Canonical URL
      alternates: {
        canonical: siteUrl,
      },
    };
    ```

    3. Add JSON-LD structured data for Person schema. Create a script tag in the body:

    In the RootLayout component, add before children:
    ```tsx
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{
        __html: JSON.stringify({
          "@context": "https://schema.org",
          "@type": "Person",
          name: portfolio.personalInfo.name,
          jobTitle: portfolio.personalInfo.title,
          description: portfolio.personalInfo.tagline,
          url: siteUrl,
          sameAs: [
            portfolio.contact.github,
            portfolio.contact.linkedin,
          ],
          knowsAbout: portfolio.skills.map(s => s.name),
        }),
      }}
    />
    ```

    4. Create a simple OG image placeholder (or note that user should add one):
       - Create `public/og-image.png` - a 1200x630 image with name and title
       - For now, can skip and just ensure the path is configured
  </action>

    2. For sitemap.xml, Next.js 16 can generate it automatically. Update `next.config.ts`:

    The site is using static export (output: "export"), so we need to create a static sitemap.

    Create `public/sitemap.xml`:
    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
      <url>
        <loc>https://example.com/</loc>
        <lastmod>2026-02-03</lastmod>
        <changefreq>monthly</changefreq>
        <priority>1.0</priority>
      </url>
    </urlset>
    ```

    Note: For a single-page portfolio, the sitemap is simple. The date should be updated on each deployment.
