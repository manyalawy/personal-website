  <action>
    1. Create `src/components/layout/SkipLink.tsx`:
    ```tsx
    "use client";

    export function SkipLink() {
      return (
        <a
          href="#main-content"
          className="sr-only focus:not-sr-only focus:absolute focus:top-4 focus:left-4 focus:z-[100]
                     focus:px-4 focus:py-2 focus:bg-accent focus:text-white focus:rounded-md
                     focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-accent"
        >
          Skip to main content
        </a>
      );
    }
    ```

    2. Update `src/app/layout.tsx`:
    - Import SkipLink: `import { SkipLink } from "@/components/layout/SkipLink";`
    - Add SkipLink as first child inside ThemeProvider (before Header)
    - Add `id="main-content"` to the main content area (the {children} wrapper or in page.tsx)

    3. Update `src/app/globals.css` with focus ring utilities:
    ```css
    /* Focus ring styles for accessibility */
    @layer utilities {
      .focus-ring {
        @apply focus:outline-none focus-visible:ring-2 focus-visible:ring-accent focus-visible:ring-offset-2;
      }
    }

    /* Ensure all interactive elements have visible focus */
    a:focus-visible,
    button:focus-visible,
    [role="button"]:focus-visible,
    input:focus-visible,
    select:focus-visible,
    textarea:focus-visible {
      outline: 2px solid var(--color-accent);
      outline-offset: 2px;
    }

    /* Screen reader only utility */
    .sr-only {
      position: absolute;
      width: 1px;
      height: 1px;
      padding: 0;
      margin: -1px;
      overflow: hidden;
      clip: rect(0, 0, 0, 0);
      white-space: nowrap;
      border-width: 0;
    }

    .sr-only.focus\:not-sr-only:focus {
      position: absolute;
      width: auto;
      height: auto;
      padding: inherit;
      margin: inherit;
      overflow: visible;
      clip: auto;
      white-space: normal;
    }
    ```
  </action>
  <verify>
    - `npm run build` succeeds
    - `npm run dev`, press Tab - skip link should appear
    - Press Enter on skip link - should focus main content
    - Tab through page - all links and buttons should have visible focus ring

    - Projects.tsx uses `<img>` for project logos

    Since this is a static export and images are external/optional, the current `<img>` usage is acceptable. Add lazy loading:
    ```tsx

    />
    ```

    **Animation Library Loading (PERF-02):**

    Framer Motion is imported in ScrollReveal which is used in all sections. This is acceptable for a portfolio where animations are a key feature. The library is tree-shaken by Next.js.

    If bundle size becomes an issue, could use dynamic import:
    ```tsx
    const MotionDiv = dynamic(() => import('framer-motion').then(m => m.motion.div), {
      ssr: false
    });
    ```
    But this is likely unnecessary for this portfolio size.

    **Performance Targets (PERF-03, PERF-04, PERF-05, PERF-06):**
