<task type="auto">
  <name>Task 1: Create portfolio data file with all content</name>
  <files>src/data/portfolio.ts</files>
  <action>
Create a TypeScript data file exporting all portfolio content. This is the single source of truth for the entire site. Include TypeScript interfaces and data for:

1. **Personal info**: name, title/role, tagline, short bio
2. **Skills**: Array of skill objects with `name`, `icon` (string identifier for the technology, e.g. "react", "typescript", "nodejs"), and `category` ("Frontend" | "Backend" | "Tools" | "Other"). Include 15-20 realistic skills for a full-stack developer.
3. **Work experience**: Array of position objects with `title`, `company`, `startDate`, `endDate` (string or "Present"), `achievements` (string array, 2-4 items each). Include 3-4 positions.
4. **Education**: Array with `degree`, `institution`, `year`. Include 1-2 entries.
5. **Projects**: Array of 6-8 project objects with `title`, `description` (2-3 sentences), `techStack` (string array), `liveUrl` (optional), `repoUrl` (optional), `icon` (optional emoji or identifier). Use realistic but placeholder project data.
6. **About**: `paragraphs` string array (3-4 paragraphs of engaging personal story).
7. **Contact**: `email`, `github`, `linkedin` URLs.

Use placeholder content that feels realistic (not "Lorem ipsum"). The user will replace with real data later. Export as `export const portfolio = { ... }` and also export the TypeScript interfaces.
  </action>
  <verify>Run `npx tsc --noEmit` to verify TypeScript compiles without errors.</verify>
  <done>Portfolio data file exists with typed interfaces and realistic placeholder content for all 7 sections.</done>
